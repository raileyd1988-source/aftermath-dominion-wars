# AFTERMATH: DOMINION WARS
## Master Game Design Document

### Genre
Online survival • Base building • Alliance strategy • PvE • PvP • Cross-server warfare

### Platforms
Android first, followed by iOS

### Audience
18+ Only

### Business Model
Free-to-play with controlled, progression-focused monetization

---

## THE VISION

AFTERMATH: Dominion Wars is a persistent online post-apocalyptic strategy game built around three core ideas:

1. **Build something worth defending**
2. **Create an alliance worth fighting for**
3. **Turn rival alliances into one army when another server invades**

### Core Philosophy

- **PLAY DAILY → PROGRESS DAILY**
- **HELP YOUR ALLIANCE → GROW FASTER**
- **PAY → GET IT FASTER**
- **PLAY → EARN IT FREE**
- **SKILL → USE IT BETTER**
- **NEVER SPEND → STILL REACH ENDGAME**
