# AFTERMATH: Dominion Wars

> THE OLD WORLD IS DEAD. WHAT YOU BUILD NEXT IS YOURS.

A persistent online post-apocalyptic strategy game featuring base building, alliance warfare, and server-scale PvP combat.

## Quick Start

```bash
# Clone the repository
git clone https://github.com/raileyd1988-source/aftermath-dominion-wars.git
cd aftermath-dominion-wars

# Install dependencies
npm install

# Run development server
npm run dev
```

## Key Features

- **Base Building**: Evolving Command Center from checkpoint to dominion city
- **Alliance Warfare**: 50-75 member alliances with dedicated leadership roles
- **Server vs Server**: Weekly cross-server competition culminating in Saturday Dominion War
- **PvE Content**: NEXUS bosses, Infected hunts, Abandoned Bunkers
- **Commander System**: Collect and upgrade unique commanders with tactical bonuses
- **Hunt Squads**: 6-player tactical alliance combat teams
- **Capital Battles**: Server-scale strategic warfare for territorial control
